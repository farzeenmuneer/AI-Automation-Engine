BUG TITLE:
================================================================================
Checkout fields accept empty values without validation on first attempt

================================================================================
ENVIRONMENT:
================================================================================
- Browser: Chrome (Latest Version)
- OS: Windows 11
- Application: Saucedemo (https://www.saucedemo.com/)
- Testing Tool: Playwright (Python)

================================================================================
SEVERITY & PRIORITY JUSTIFICATION:
================================================================================
Severity: LOW
- Users are not blocked from completing their purchase
- No data loss or security risk involved
- Error message appears after validation check

Priority: P3
- Not a critical path issue
- Users can still proceed by entering data
- No financial impact

================================================================================
DESCRIPTION:
================================================================================
When navigating through the checkout process, the "Continue" button does not
immediately validate required fields (First Name, Last Name, Postal Code) on
the first click. Validation only occurs after a slight delay, which could
lead to a poor user experience.

================================================================================
STEPS TO REPRODUCE:
================================================================================
1. Login with valid credentials (standard_user / secret_sauce)
2. Add item to cart (Sauce Labs Backpack)
3. Go to cart
4. Click "Checkout"
5. Leave First Name, Last Name, and Postal Code fields EMPTY
6. Click "Continue" button
7. Observe the validation behavior

================================================================================
EXPECTED RESULT:
================================================================================
Validation should occur immediately. A red border should appear on empty fields
with a clear error message: "Error: First Name is required."

================================================================================
ACTUAL RESULT:
================================================================================
The "Continue" button initially appears to accept empty fields. After a slight
delay, the validation is triggered and the error message is displayed.

================================================================================
ROOT CAUSE ANALYSIS:
================================================================================
The issue was caused by a missing validation trigger on the "Continue" button
click event. The validation function was only being called after a delay,
allowing users to bypass the initial check.

Fix Implemented:
- Added validation to the onClick event of "Continue" button
- Error message now appears immediately
- Fields with errors are highlighted
